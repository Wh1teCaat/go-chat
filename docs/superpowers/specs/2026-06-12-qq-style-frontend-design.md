# QQ 风格前端重设计

## 目标

将当前聊天应用前端重构为 QQ 经典双栏结构，重结构不重美观。文件/图片功能预留接口，暂不实现。

## 整体布局

```
┌──────────────────────┬───────────────────────────────────┐
│   左侧面板 (~280px)   │         右侧聊天区                  │
│                      │                                   │
│  ┌────┬────────────┐ │  ┌──────────────────────────────┐ │
│  │头像 │ 用户名      │ │  │  联系人名称         群成员按钮 │ │
│  │    │ ●在线/离线  │ │  ├──────────────────────────────┤ │
│  ├────┴────────────┤ │  │                              │ │
│  │    搜索框        │ │  │   消息列表（气泡模式）          │ │
│  ├─────┬────┬─────┤ │  │   - 对方：头像 + 灰色气泡       │ │
│  │消息  │好友 │群组  │ │  │   - 自己：蓝色气泡靠右          │ │
│  ├─────┴────┴─────┤ │  │   - 时间分隔线                  │ │
│  │                │ │  │                              │ │
│  │  会话列表      │ │  ├──────────────────────────────┤ │
│  │  (头像+名称    │ │  │  工具栏（表情/图片/文件占位）    │ │
│  │   +最后消息    │ │  ├──────────────────────────────┤ │
│  │   +时间)      │ │  │  输入框 + 发送按钮              │ │
│  │                │ │  └──────────────────────────────┘ │
│  ├────────────────┤ │                                   │
│  │ 退出登录        │ │                                   │
│  └────────────────┘ │                                   │
└──────────────────────┴───────────────────────────────────┘
```

## 左侧面板

| 组件 | 说明 |
|------|------|
| 用户头像 | 40px 圆形占位，昵称首字，颜色按用户 ID 计算 |
| 在线状态 | WS open → 绿点 + "在线"；close/error → 灰点 + "离线" |
| 搜索框 | 输入文字实时过滤会话列表 |
| Tab 切换 | 消息 / 好友 / 群组，点击切换列表 |
| 会话列表 | 消息 tab：头像+昵称+最后消息+时间；好友 tab：好友列表；群组 tab：群列表 |
| 操作区 | 好友 tab 顶部：添加好友 + 待处理申请；群组 tab 顶部：建群/加群/入群审批 |
| 退出按钮 | 左下角，红色文字 |

## 右侧聊天区

| 组件 | 说明 |
|------|------|
| 标题栏 | 联系人名称、群成员数量、群成员按钮（仅群聊） |
| 消息气泡 | 对方：左侧头像 + 灰色气泡；自己：蓝色气泡右对齐，无头像。文本内容 |
| 时间分隔 | 消息间隔超过 5 分钟插入居中时间标签 |
| 工具栏 | 😊 🖼 📎 三个按钮，预留回调，当前只 console.log |
| 输入区 | textarea + 发送按钮，Enter 发送 / Shift+Enter 换行 |

## 群成员面板

右侧滑出覆盖消息列表，结构与当前基本一致。

## 文件预留接口

- `avatar_url` 字段：头像渲染时优先读取，为空则使用占位
- 工具栏按钮：绑定 `onEmoji` / `onImage` / `onFile` 空回调，触发时打 log

## 涉及文件

- `web/index.html` — 重写 HTML 结构
- `web/styles.css` — 重写 CSS
- `web/app.js` — 适配新结构，改消息渲染、WS 状态映射、tab 切换逻辑
- `web/app-helpers.js` — 尽量少改

## 不变内容

- 后端 API 调用不变
- WebSocket 协议不变
- 登录/注册流程不变
- 好友/群组管理逻辑不变
