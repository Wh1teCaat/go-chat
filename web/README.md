# Chat Proj Web

这是一个用于手动测试后端接口的简易聊天页。

## 启动

```bash
cd web
npm run dev
```

然后打开：

```text
http://localhost:5173
```

默认后端地址是 `http://localhost:8080`，登录页可以修改。

## 使用流程

1. 先通过登录页下方的注册链接注册两个用户。
2. 用其中一个用户登录。
3. 在左侧输入另一个用户的邮箱，点击“添加”。
4. 换另一个用户登录，在“待处理”里接受申请。
5. 左侧会话列表出现会话后，选中会话并在右侧聊天窗口发送消息。
6. 群主或管理员会收到入群申请推送，也可以在“入群审批”里查看自己可审批的所有申请并批准/拒绝。
7. 打开群聊后，右上角“群成员”可查看成员；群主可以设置/取消管理员、移除成员或转让群主。

## 当前能力

- 登录、注册
- 登录页和注册页切换
- 通过邮箱添加好友、接受/拒绝好友申请
- 创建群、申请加群、审批入群申请
- 群成员列表和群主权限管理
- QQ 式左侧会话列表和右侧聊天窗口
- WebSocket 发送和接收聊天消息
- 调试日志

## 登录恢复

登录状态与待重试的刷新请求保存在 `chatAuthSession` 中；升级时自动迁移旧存储。断网或服务暂时不可用时，刷新沿用同一个请求标识重试，保留登录状态。重载页面会立即继续待完成刷新，明确收到刷新 401 后回到登录页。

服务端提供最多 60 秒的结果恢复窗口，超出窗口且没有收到新令牌时仍需重新登录。支持 Web Locks 的浏览器可协调同源多个标签页（通常需 HTTPS 或 localhost）；不支持时仅合并单页内的刷新请求。日志中的令牌与密码字段会脱敏。
